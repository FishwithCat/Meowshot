# Meowshot

自用的原生 macOS 菜单栏截屏工具，无第三方依赖。需要 macOS 13+ 和 Xcode Command Line Tools。

```sh
bash build.sh --run
```

构建产物位于 `.build/Meowshot.app`，可复制到「应用程序」文件夹后运行。菜单栏的取景框图标是入口，App 不显示 Dock 图标。

- `⌘⇧X`：拖拽框选截图区域，拖动内部移动选区、拖动边缘或角调整大小；`Enter` 确认截屏，`Esc` 取消。
- 按 `Enter` 后截图直接进入剪贴板，不弹出预览窗口；在目标应用按 `⌘V` 粘贴。
- 首次截屏需在系统设置中允许 Meowshot 录制屏幕，再重新启动 App。

请固定使用同一路径下的 App。构建脚本会复用未修改的构建，避免重复签名。默认使用临时签名，修改代码并重新构建后可能需要重新授权：退出 Meowshot，在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中移除旧的 Meowshot，再用 `+` 添加当前 `.build/Meowshot.app`（或你实际使用的应用程序目录中的副本），开启权限后重新打开。

若本机有代码签名证书，可用 `CODE_SIGN_IDENTITY="证书名称或 SHA-1" bash build.sh --run` 构建；后续构建保持使用同一证书，有助于保留授权。可用 `security find-identity -v -p codesigning` 查看可用证书。没有证书时，临时签名无法保证跨版本保留授权。

每次截图会替换剪贴板内容；需要保留的截图请先粘贴到其他应用保存。不生成截图文件，不上传任何内容。

验证构建与截屏参数：

```sh
bash build.sh --test
```

手动验收：授权后完成选区截图，确认不出现系统截图工具栏；区域选框移动和缩放后松开鼠标应仍保留，按 Enter 后不弹出窗口，按 Esc 应取消且保留剪贴板原内容；在预览或聊天软件按 ⌘V，确认粘贴的图片对应选区。拒绝权限时应显示引导，快捷键被占用时可从菜单栏操作。
