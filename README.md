# Meowshot

自用的原生 macOS 菜单栏截屏工具，无第三方依赖。需要 macOS 13+ 和 Xcode Command Line Tools。

```sh
bash build.sh --run
```

构建产物位于 `.build/Meowshot.app`，可复制到「应用程序」文件夹后运行。菜单栏的取景框图标是入口，App 不显示 Dock 图标。

- `⌘⇧X`：拖拽框选截图区域，拖动内部移动选区、拖动边缘或角调整大小；`Enter` 复制图片，`⌘Enter` 提取并复制文字，`Esc` 取消。
- 选区不显示操作条；按确认后不弹出预览窗口，在目标应用按 `⌘V` 粘贴。
- OCR 在本机通过系统 Vision 识别简体中文、繁体中文和英文，复制全部纯文本并保留识别到的换行，不还原段落或表格。识别中可按 `Esc` 取消；不显示操作说明、识别状态或结果提示。无文字、识别失败或取消均保留原剪贴板。
- 首次截屏需在系统设置中允许 Meowshot 录制屏幕，再重新启动 App。

请固定使用同一路径下的 App。构建脚本会复用未修改的构建，避免重复签名。默认使用临时签名，修改代码并重新构建后可能需要重新授权：退出 Meowshot，在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中移除旧的 Meowshot，再用 `+` 添加当前 `.build/Meowshot.app`（或你实际使用的应用程序目录中的副本），开启权限后重新打开。

若本机有代码签名证书，可用 `CODE_SIGN_IDENTITY="证书名称或 SHA-1" bash build.sh --run` 构建；后续构建保持使用同一证书，有助于保留授权。可用 `security find-identity -v -p codesigning` 查看可用证书。没有证书时，临时签名无法保证跨版本保留授权。

复制图片或成功识别文字会替换剪贴板内容；需要保留的内容请先粘贴到其他应用保存。OCR 使用私有临时目录中的截图，载入识别前即清理，失败或取消时也会清理。不保留截图文件，不上传任何内容。

验证构建、选区行为、动作分派、临时截图参数、剪贴板保护，以及生成的中英文图片和空白图片的实际 OCR（需要可访问 macOS 桌面服务；测试使用独立剪贴板，不修改日常剪贴板）：

```sh
bash build.sh --test
```

手动验收：

- 授权后移动、缩放选区，松开鼠标仍保留；屏幕边缘及多显示器下均可正常框选。
- 分别用 Enter／⌘Enter，确认图片／文字可粘贴到原应用，不弹出结果窗口，图片不包含选框。
- 测试简繁中文、英文混排、多行及空白区域；确认文字保留换行，空白区域不弹出提示且保留剪贴板。
- 框选时及识别中按 Esc，确认取消且保留剪贴板；取消后立刻重新截图，旧识别结果不能覆盖新内容。识别中重复触发快捷键不得启动另一任务。
- 拒绝权限时显示引导，快捷键被占用时仍可从菜单栏操作；识别失败不弹出提示并保留剪贴板。
